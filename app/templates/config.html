Earn (idle USDT sweep)

When on, idle USDT routes into the venue's yield surface. Binance PM: bot calls /sapi/v1/portfolio/mint (USDT→BFUSD) and /sapi/v1/portfolio/redeem (BFUSD→USDT). BFUSD is PM cross-collateral so it stays usable as margin while earning yield. KuCoin UTA: auto-lend handles routing — toggle it per asset in KuCoin UI → Margin → Lending → Auto-Lend. Auto-lent USDT continues to count as cross-margin collateral; the bot only reads the balance and surfaces it on the dashboard. KuCoin Classic: bot moves idle USDT to the funding (main) wallet which is the auto-lend source; same UI toggle applies. Disabling leaves idle USDT in the trading wallet earning nothing.
